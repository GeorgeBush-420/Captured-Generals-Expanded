CGE COMPAT SKRIPT

Requirementz

- Python 3.11+
- ParadoxParser by Dao

to install reqs, do

    python -m pip install -r requirements.txt

usage

    python cge_compat.py --source-mod "path/to/target/mod" --cge-mod "path/to/cge/mod" --output "path/to/compat/submod"

u can do --force to replace the existing output folder.

other args which i hope are self explanatory

    --submod-name "CGE - (for example) kaiserreich compat"
    --supported-version "1.17.*"
